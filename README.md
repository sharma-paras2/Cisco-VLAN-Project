# Cisco VLAN Project

This project demonstrates a network topology created using Cisco Packet Tracer.

## Project Overview

* 3 separate labs created
* 10 PCs in each lab
* Each lab assigned to a different VLAN
* Each VLAN connected through switches
* Main switch connected with DHCP server and router

## VLAN Structure

* VLAN 10 → Lab 1
* VLAN 20 → Lab 2
* VLAN 30 → Lab 3

## Components Used

* Cisco Switches
* Router
* DHCP Server
* End Devices (30 PCs)

## Features

* VLAN segmentation
* DHCP IP assignment
* Inter-device connectivity
* Centralized switching design

## Software Used

* Cisco Packet Tracer
